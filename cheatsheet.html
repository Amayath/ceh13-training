Password cracking — commandes types

  • Hashcat — hashcat -a 0 -m 0 hash.txt rockyou.txt (-a mode d'attaque, -m type de hash)
  • Hydra — hydra -l user -P wordlist.txt <ip> <service>
  • John the Ripper — unshadow passwd.txt shadow.txt > hash.txt puis john hash.txt
  • SQLMap — sqlmap -u <url> --dbs --random-agent
